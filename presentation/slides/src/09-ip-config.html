COMMON CSR CONVENTION
  • AXI4-Lite 32-bit data, 6-bit local byte address, 모든 offset 4-byte aligned
  • W1P (Write-One-Pulse) register는 write transaction에서만 1-clock pulse를 만들고 read = 0
  • Reserved bit는 write 시 무시, read 시 0 반환
  • 세 IP 모두 s_axi_aclk = 100 MHz, s_axi_aresetn = sync active-low
  • Naming — module lower_snake_case, port _i / _o / _ni, param UPPER_SNAKE
Interface Metadata packaged BRAM_PORTA = BYTE_ADDRESS · MEM_WIDTH=32 · MEM_SIZE=4096 고정 — 기본값 8192를 두면 Block Automation이 BMG depth를 2048로 바꾼다.
