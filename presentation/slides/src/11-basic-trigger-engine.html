Basic Trigger Engine IP

Custom IP · 담당 국승호
Core Role
  • 8-bit sample에 대한 실시간 Trigger 조건 판정
  • Rising · Falling · Masked Pattern 세 Mode를 한 번에 하나만 활성화
  • Trigger pulse는 combinational — 판정된 그 sample과 같은 cycle에 정렬 (1-cycle 지연 없음)
  • One-shot — Trigger 이후 CLEAR 전까지 추가 pulse 없음
  • Pattern은 진입(entry) 검출 — 조건이 유지돼도 한 번만 Trigger
  • ARM 직후 첫 valid sample은 비교 기준만 생성
