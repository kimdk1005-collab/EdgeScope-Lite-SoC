Circular Trace Buffer IP

Custom IP · 담당 윤형욱
Core Role
  • 1,024 × 32-bit True Dual-Port BRAM에 8-bit sample을 circular write
  • Trigger 직전 512 + Trigger 포함 이후 512 보존, Logical trigger index 512 고정
  • BRAM word = {24'b0, sample_data}, byte write enable 4'b1111
  • Port A는 capture write, Port B는 MicroBlaze read 전용
  • 완료 시 START_ADDR · TRIGGER_ADDR · WRITE_ADDR와 level-high IRQ 제공
  • 제어 우선순위 reset > abort > clear_done > arm > capture
